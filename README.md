# 📊 SQL Business & Sales Analysis

## 📌 Project Overview

This project analyzes a sample sales dataset using SQL to explore sales performance, customer behavior, product performance, geographical trends, and monthly revenue.

The goal is to demonstrate practical SQL skills relevant to Data Analyst and Business Intelligence roles.

## 🎯 Business Questions

- What is the total revenue?
- Which products generate the most revenue?
- Which countries generate the highest sales?
- Which products sell the most units?
- Which categories generate the most revenue?
- What are the highest-value orders?
- What is the average order value?
- How does revenue change by month?
- Which customers spend the most?

## 🗂️ Dataset

The dataset contains the following columns:

| Column | Description |
|---|---|
| order_id | Unique order ID |
| order_date | Date of order |
| customer_name | Customer name |
| country | Customer country |
| product | Product purchased |
| category | Product category |
| quantity | Number of units |
| unit_price | Price per unit |
| sales | Total sales value |

## 🔎 SQL Analysis

The project contains SQL queries for:

1. Viewing the complete dataset
2. Calculating total revenue
3. Sales by product
4. Sales by country
5. Best-selling products by quantity
6. Sales by category
7. Highest-value orders
8. Average order value
9. Monthly sales trends
10. Customer spending analysis
